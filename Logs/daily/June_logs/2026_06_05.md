**Daily Log**

**Anneal V2 — Architecture & Refactor Notes (Session Summary)**

**Overview**:

Anneal V2 has been refactored from a single monolithic file into a modular system with clear separation of responsibilities 100% complete:

-data generation

-feature construction

-model architecture

-training loop

-evaluation

-visualization

-utilities


The system has transitioned from monolithic execution → explicit pipeline architecture

**Final Module Structure**

**anneal_main.py**

**Role**: orchestration layer

-Initializes config

-Builds model

-Generates data

-Calls training

-Calls evaluation

-Calls visualization

**Does NOT construct internal tensors or logic**


**anneal_model.py**

**Role**: computation + forward logic

Defines ProbTrajectory5k

**Owns**:

-time encoding logic

-branch projection (branch_proj)

-forward pass

-MLP Branch


**Receives all inputs externally**

No data generation or training logic


**anneal_train.py**

**Role**: optimization loop

-train_on_synthetic

-owns optimizer

-runs backprop

-evaluation helper functions

**does NOT construct**:

-model

-config

-tensors

-features

**anneal_data.py**

**Role**: synthetic trajectory generation

-generate_random_trajectory

-produces training data only

-no model awareness

**anneal_util.py**

**Role**: feature + tensor utilities

-Build_features

-ensure_traj3D

-smooth_tensor


**Must NOT import model or config (to avoid circular dependencies)**

**nneal_eval_viz.py**

**Role**: visualization

-trajectory visualization

-plotting outputs from model predictions

-NO training logic

**anneal_config.py**

**Role**: system parameters

-latent_dim

-base_dim

-num_branches

-hyperparameters


**Pure definitions only**

**Key Architecture Fixes Identified**

-Branch embedding duplication bug

**Wrong pattern**:

-branch_embed created in main AND projected in model incorrectly

**Correct pattern**:

-main → generates input state

-model → transforms state via branch_proj

**Time encoding duplication bug**

**t_feat was**:

-passed externally

-AND recomputed internally

**Fix**:

-model owns time encoding

-eval/training do NOT inject it externally

**Circular import issue**

**Found in config/model cross-import**:

-anneal_config → anneal_model → anneal_config

**Fix**:

-config must be dependency-free

-model imports config, NOT reverse

**Tensor construction drift**

**Found in multiple locations**:

-main

-model

-util

**Fix**:

**tensors belong ONLY in**:

-data

-util

-main (orchestration only)


**Training file over-responsibility**

**training originally contained**:

-tensor creation

-feature logic

-evaluation logic

-logging mixing


**Now reduced to**:

-optimizer

-forward pass

-loss

-backward step

**Architectural Principles Established**

**Ownership Rule**

-Each object has exactly ONE owner module

**Construction Rule**

-Only data/config/model/main may construct objects

**Execution Rule**

-training/eval/viz only execute, never construct

**No hidden globals rule**

-All dependencies must be passed explicitly

**Known Runtime Observations**

**Positive**

-system successfully runs end-to-end

-modularization is stable

-training loop executes cleanly

**Issues now appearing (post-refactor stage)**

**These are now true logic/runtime issues, not structural**:

-tensor mismatches (likely shape propagation)

-evaluation input inconsistencies

-possible stale branch embedding usage

-time encoding alignment checks needed

**Next Debug Phase (recommended order)**

-Verify tensor shapes across pipeline

-Ensure time encoding single-source-of-truth

-Validate evaluation vs training parity

-Stress test multi-branch scaling

**This refactor reached a key milestone**:

-architecture is no longer the problem — correctness is now local

-System fully modularized
