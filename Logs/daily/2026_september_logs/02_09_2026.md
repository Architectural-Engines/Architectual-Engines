**Alpha Weighting**

**Branch logits are one scalar per branch**:

branch_logits = [1]

**Alpha is therefore**:

self.alphas = F.softmax(self.branch_logits, dim=0)

**giving**:

alphas = [55]

Alpha represents one weighting value per branch, not one value per state dimension.

Branch weight to be broadcasted across the complete branch interaction volume rather than reshaped:

self.alphas[:, None, None, None]

Preserves the semantic distinction:

one branch
    ↓
one α
    ↓
entire branch interaction volume

Branch Variance

Branch variance compares each branch interaction against the incoming latent state while retaining the branch population for the variance calculation.

**Conceptually**:

interaction_real [55,20,4,3]
        ↓
compare against latent_real_in
        ↓
squared branch deviations
        ↓
Alpha weighting
        ↓
sum across branches

Previous implementation incorrectly attempted:

self.alphas.view(55, 20, 3)

Alpha contains only 55 values.

Correct conceptual operation for broadcasting:

alpha_variance = self.alphas[:, None, None, None]

self.branch_variance = (
    (self.interaction_real - self.latent_real_in.unsqueeze(0)) ** 2
    * alpha_variance
).sum(dim=0)

Branch variance is treated as a diagnostic/uncertainty calculation rather than part of the core state-generation transformation.
