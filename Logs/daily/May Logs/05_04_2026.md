
**Session Debug Summary — ProbTrajectory5k / Anneal System**

branch embeddings

**Major Systems Involved**

**Final pipeline**:

      ↓
   mlp1

      ↓
 out_proj → pos_pred (3D)

**Branch MLP Bug (Resolved)**

**Error**:

RuntimeError: mat1 and mat2 shapes cannot be multiplied

**Root cause**:

mlp_input_dim incorrectly defined or mismatched with actual concatenated tensor:

x = cat([embed, t_feat]) → shape mismatch vs Linear(in_features)

**Fix**:

**Ensure**:

mlp_input_dim = config.embed_dim + config.time_feat_dim

self.mlp1 = nn.Linear(mlp_input_dim, hidden_dim)


**Forward/Return Signature Mismatch**

**Error**:

ValueError: too many values to unpack (expected 4, got 9)

ValueError: not enough values to unpack (expected 4, got 3)

**Cause**:

Forward pass return signature changed mid-refactor

Training loop still expected old structure

Required stabilization:

Ensure single contract:

return pos, unc, resolved_state, branch_out

or explicitly simplify to:

return pos, resolved_state, branch_out

BUT must match training unpacking exactly.

**Loss Explosion Due to Shape Drift**

**Error**:

RuntimeError: size mismatch (132 vs 3)

**Cause**:

pos_pred became latent-sized tensor instead of decoded output

out_proj not properly applied in all branches

**Ensure final output is always**:

pos_pred.shape == [B, T, 3]


**Autograd Break (Critical Issue)**

**Error**:

RuntimeError: element 0 of tensors does not require grad

**Root cause categories**:

.detach() used before loss

.cpu().numpy() inside computation path

torch.no_grad() accidentally wrapping training 

evaluation helper reused in training path

**Fix rule**:

Evaluation ≠ Training

evaluation uses torch.no_grad()

training must preserve full graph

**Loss / Evaluation Separation Bug**

Problem pattern discovered

with torch.no_grad():

    pos = model(...)
    
    loss = mse(pos, target)

Then returned and reused incorrectly in training.
Fix:

Evaluation must return:

pos, uncertainty, resolved_state

NOT loss.

**Uncertainty System Conflict**

Two overlapping definitions:

A) **Model output**:

unc

B) **Derived**:

unc = branch_out.abs().mean(dim=1)

**Issue**:

inconsistent usage across training + logging

duplicated semantics

Recommendation:

**Choose ONE**:

model-provided uncertainty OR
derived uncertainty only
NOT both simultaneously.

**Logging System (Timelogger / PerfLogger)**

**Components**:

ops_count instrumentation

**Issue discovered**:

logging logic was bleeding into computation graph

**Fix principle**:

Logging must never modify tensors used in backprop
