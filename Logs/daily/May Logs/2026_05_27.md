**Anneal — Coding Session Notes (Refactor + Debug Cycle)**

**Overview**

-**This session focused on stabilizing Anneal’s branch–latent interaction model, resolving cascading tensor mismatches caused by**:

-dimensional collapse of branch_out

-removal/replacement of time encoding pipeline

-inconsistent feature semantics (input vs latent vs target)

-accidental preprocessing of ground truth targets

-duplicated uncertainty signals

-evaluation function signature drift


-The system is now transitioning from experimental construction → structured architecture stabilization.

**Major Architectural Changes**

**Branch Collapse Refactor**

**Old structure**:

branch_out: [B, T, 3, sd]

**New structure**:

branch_out: [B, T, latent_dim]

**Impact**:

-All interaction math had to be rewritten

-Loss of implicit dual-channel interaction space

-Required redefinition of interaction_real / interaction_imag flow

 
**Time Feature Drift (t_feat)**

**Issue discovered**:

-t_feat originally 16-dimensional

-accidentally collapsed to 3-dimensional via preprocessing pipeline changes

**Root cause**:

-time logger removed

-prep_trajectory unintentionally influencing time feature pipeline

-mixing raw trajectory preprocessing with learned embeddings


**Fix**:

Separate:

-prep_trajectory(t_traj) → raw temporal structure

-time_encoder() → latent feature space (16-dim restored)

**Rule established**:

> prep_trajectory ≠ feature encoder


**Target Leakage Bug**

**Critical issue**:

-pos_target_clean = prep_trajectory(pos_target)

**Problem**:

-Ground truth labels were incorrectly transformed

-introduced distortion in loss space

-model learned warped representation of outputs


**Fix**:

-pos_target must remain RAW ground truth

-only inputs are preprocessed


**Tensor Dimension Contract Breaks**

**Example failure**:

MLP mismatch: got 135, expected 148

**Root cause**:

132 (embed) + 3 (t_feat) = 135
132 + 16 = 148

**Fix**:

-restored missing 16-dim temporal embedding path

-enforced strict feature concatenation contract


**Circular Dependency Bug (P_lat / branch math)**

**Issue**:

-P_lat used before initialization

-residual dependency from removed architecture branch

**Fix**:

-removed orphaned dependency

-corrected factor computation:

-factor = branch_out_dim // P_lat_dim


**Evaluate Model Signature Drift**

**Issue**:

-evaluate_model expected legacy outputs:


**trajectory, latent_real_out, latent_imag_out, branch_out, pos_pred**

**Problem**:

**forward pass only return**:

-pos_pred, unc, latent_real, latent_imag, branch_out

**Fix**:

aligned evaluation pipeline with forward signature

-removed outdated dependency chain


**Motion Type Argument Collision**

**Issue**:

-got multiple values for argument 'motion_type'

**Cause**:

-motion_type passed multiple times across:

-positional args

-keyword args

-internal forward defaults


**Fix**:

**enforced keyword-only definitio**n:

-def forward(..., *, motion_type="circular")


**Uncertainty Signal Duplication**

**Issue**:

**Two competing definitions**:

-uncertainty = latent_imag_out.abs().mean(dim=1)
-unc = branch_out.abs().mean(dim=1)

**Problem**:

-semantic ambiguity in diagnostics

-inconsistent logging signals

**Fix**:

**standardized on ONE**:

-uncertainty = latent_imag_out.abs().mean(dim=1)

**Key Design Principles Established**

**Separation of Spaces**

-Raw space → preprocessing only

-Latent space → learned embeddings

-Target space → NEVER transformed

**Feature Contract Enforcement**

**All model concatenations must obey**:

embed_dim + time_feat_dim = MLP input dim


**No Dual-Semantic Signals**

**Each concept must have ONE source**:

-uncertainty → latent_imag_out only

-branch signal → structural decomposition only (not reused)

**Immutable Ground Truth Rule**

pos_target must never be transformed


**Pipeline Ownership Rule**

**Each stage owns its responsibility**:

Stage Responsibility

-prep_trajectory raw input shaping
-time_encoder latent time features
-branch_mlp structural decomposition
-model.forward integration only
